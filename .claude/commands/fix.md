# Fix lint and type errors

Fix all linting, formatting, and type issues.

## Steps

1. Run `pnpm format` to auto-fix formatting with Prettier
2. Run `pnpm lint:fix` to auto-fix ESLint issues
3. Run `pnpm check` to check for TypeScript errors
4. Read files with remaining errors and apply fixes
5. Re-run all checks to confirm everything passes
